## 修复内容

macOS 的纹理可以使用较紧凑的行宽。例如，12 × 3 的 RGBA16Float 纹理每个像素占 8 字节，96 字节已经足以放下一行有效像素，但仍可能不满足宿主 GPU 对 buffer-backed texture 的额外对齐要求。Test 1 会拒绝这种直接映射，部分路径留下空纹理。

Test 2 为符合范围与格式限制的单层二维映射表面增加复制路径，覆盖上述 RGhA / RGBA16Float 小表面，以及受支持的 BGRA 小表面。只处理与表面原始宽高一致、可见像素数据不超过 1 MiB 的情况。

在宿主创建独立纹理，在执行绘制前从原来的 buffer 上传像素，并在写入资源后把像素复制回去。复制与绘制使用同一个 Metal command buffer；保留原来的行宽、偏移和行间填充。同一表面的纹理视图共享一个底层纹理，避免在多个 GPU 绘制阶段之间读到各自复制的旧像素。

**普通 buffer 上的 linear texture 对齐失败暂未纳入此复制路径。** 那条路径还涉及 buffer 与纹理间的别名同步，不能安全地套用同一个简单复制方案。因此本版是范围有限的绘制修复，不能据此承诺所有缺失的候选内容都会恢复。

这个路径会增加少量纹理存储和 GPU 复制开销，实际影响取决于触发次数。正常可直接映射的纹理继续走原有路径。多平面 IOSurface、主屏显示配置和 macOS 磁盘格式没有迁移步骤。

布局校验检查像素大小、可访问范围、行宽和偏移对齐，避免整数溢出；不将任意不支持的描述符强行解释为二维彩色纹理。

### 验证范围

新增检查使用与生产代码相同的布局与复制函数：

- 合成的紧凑行宽、边界、越界与溢出用例。
- 原生 Metal 像素上传、读回、GPU 写入、纹理视图及行间填充检查。
- 原有的安装包、宿主服务和诊断测试。
- iOS App 的实际编译、签名验证和安装包结构检查。

原生 Metal 测试需要可用的 GPU。测试环境无 Metal 设备时会明确标记跳过，不把这一情况计为像素测试通过。具体执行结果以对应 CI 日志为准。

## 安装与对照

1. 保留上一版安装包和重要 VM 的备份。不要先卸载 Henge，也不需要重新安装 macOS。
2. 在 TrollStore 用 Test 2 包更新现有 Henge。核对版本 **0.4.0 / 4002**、测试名称和源码提交。
3. 首轮继续使用原来的 VM、RAM、显示分辨率和代码缓存设置，使版本成为唯一主要变化。
4. 先在 macOS“文本编辑”输入 `nihao`，不按空格，观察候选窗口。若仍不显示，在 Henge Details 中点击 **Mark missing input candidates**，记下时间，再验证空格是否仍能提交“你好”。
5. 候选窗口测试后，再测试原先触发退出的 Chat 切换动作。记录是 Henge 回到 iPad 桌面、VM 画面停止，还是来宾里的单个客户端退出。
6. 如果 Henge 退出，只重开一次，先不要启动 Mac，立即导出 Diagnostics，以保留上一轮日志。

若仍出现内存警告，可另做一轮 **512 MB** 代码缓存对照，其他设置保持一致。缓存调整需要完整退出并重新打开 Henge；仅重启来宾 macOS 不会重新分配它。较小缓存可能增加翻译缓存刷新并降低速度，不能保证消除退出。

## 如何区分退出原因

应用日志突然中止并不能单独证明 Jetsam。内存警告表明当时有内存压力，但最终退出仍可能需要系统报告区分。

Henge 的部分虚拟机 RAM 被分配在进程 footprint 统计之外，因此 Diagnostics 的 allocation headroom 不能当作 iPad 的物理空闲 RAM。resident 与 footprint 也不能直接相加计算总占用。

如果再次退出，请提供同一时刻的 Henge Diagnostics，以及 iPadOS“设置 → 隐私与安全性 → 分析与改进 → 分析数据”中的 `Henge…ips` 或 `JetsamEvent…ips`。分析 Jetsam 时必须确认被终止的进程是对应的 Henge，不能只凭同一天存在一个 JetsamEvent 文件得出结论。

参考：[Apple Jetsam 报告说明](https://developer.apple.com/documentation/xcode/identifying-high-memory-use-with-jetsam-event-reports)、[Metal 线性纹理对齐要求](https://developer.apple.com/documentation/metal/mtldevice/minimumlineartexturealignment(for:))。
